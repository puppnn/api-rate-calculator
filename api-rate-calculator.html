分项倍率 = 分组倍率 × 中转单价 / 官方单价 / 每元可买刀数
加权倍率 = 实际人民币花费 / 官方基础成本
每 1M tokens 花费 = 中转单价 × 分组倍率 / 每元可买刀数
倍率是相对官方价的比较，不等于绝对花费；缓存命中率更高通常会降低绝对成本，但如果中转缓存分项倍率高于输入分项倍率，加权倍率可能会上升。
在线价格来自 LiteLLM 模型价格库；内置预设最后整理于 2026-05-14。大额使用前建议核对： OpenAI、 Anthropic、 Google Gemini。
